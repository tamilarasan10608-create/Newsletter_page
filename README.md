# Responsive Newsletter Webpage

A clean, modern and responsive newsletter webpage designed for **John Rodriguez**, built using HTML5 and CSS3. This project converts desktop and mobile design references into a functional browser-based webpage.

## Project Overview

The Responsive Newsletter project focuses on creating a visually appealing newsletter layout that works across mobile, tablet and desktop screen sizes.

The webpage includes newsletter branding, an introductory hero section, article content, a weekly checklist and footer navigation.

## Technologies Used

- **HTML5** – Semantic webpage structure.
- **CSS3** – Styling, typography, colors and spacing.
- **CSS Grid** – Responsive two-column layouts.
- **Flexbox** – Element alignment and positioning.
- **Media Queries** – Mobile and tablet responsiveness.
- **SVG** – Scalable logo and illustration assets.
- **Google Chrome** – Browser testing.
- **Visual Studio Code** – Development environment.

## How to Run the Project

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

Open the extracted project folder in Visual Studio Code.

### 3. Run the local server

Open the VS Code terminal and execute:

```bash
python -m http.server 8000
```

### 4. Open in your browser

Visit:

```text
http://localhost:8000
```
